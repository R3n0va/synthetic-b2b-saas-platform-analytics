# PostgreSQL Runbook

## Requirements

- local PostgreSQL instance;
- credentials configured in `.env`;
- permission to connect through `PGMAINTENANCEDB`;
- `CREATEDB` permission when the configured target database does not yet exist;
- permission to create and drop project schemas in the target database.

## Build

```console
py scripts/build_postgresql.py
```

The script selects `data/generated/default` when present and otherwise uses `data/generated/sample`. Use `--input` to select another generated directory. The target database is created automatically when it does not exist.

Equivalent direct Python command:

```console
.venv\Scripts\python.exe -m b2b_saas_platform_analytics.cli db-build --env-file .env --input data/generated/sample --project-root . --reset
```

## Build sequence

1. Create metadata, landing, core, mart, analytics and quality schemas.
2. Create contract-driven landing tables as text.
3. Load CSV files through PostgreSQL `COPY`.
4. Create typed core tables from contract types.
5. Apply primary keys, foreign keys and relationship indexes.
6. Build enriched core views and business indexes.
7. Build subscription, account, product, billing and experiment marts.
8. Build analytical views.
9. Execute 50 quality controls and record-level reconciliations.
10. Mark the metadata pipeline run as succeeded, or record the failure after rollback.

## Verification queries

```sql
SELECT * FROM metadata.latest_pipeline_run;
SELECT * FROM metadata.source_row_counts ORDER BY table_name;
SELECT * FROM quality.summary;
SELECT * FROM analytics.latest_executive_scorecard;
SELECT * FROM analytics.monthly_mrr_bridge ORDER BY month_start;
```
## Integer CSV compatibility

Generated integer fields are serialised without decimal suffixes, including nullable
columns. The loader also accepts integer-equivalent legacy values such as `0.0` or
`20.0`, which can exist in datasets generated by an earlier project version. Genuine
fractional values still fail instead of being rounded or truncated.
